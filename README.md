# Boot and CMD Simulation

Command Line Interface (CLI) simulation program created using python. The program does not use internal memory/OS packages, the program purely uses the basic logic of the Python programming language.

## Install

- Clone repository

```bash
$ git clone https://github.com/FuadGrimaldi/simulasi-booting-cmd.git
```

- Change directory into the folder

```bash
$ cd simulasi-booting-cmd
```

- run script

```bash
$ python simulasi_proses_boot.py
```

- Or just run it through a text editor
